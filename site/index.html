macOS menu-bar app and widgets

Know whether you'll run out before the reset.

Agent Usage shows your Claude, Codex and Copilot usage limits in the menu bar and in desktop widgets. A pace marker on each bar shows how much you'd have used by now at an even rate, so you can see at a glance whether you're ahead of your allowance or behind it.

How pace works

The marker is where you'd be at an even rate

Every Limit runs over a window: five hours for a Claude session, a week for the weekly limit. The marker sits at the share of that window that has gone by. Two hours before a 5-hour session resets, three hours have passed, so the marker is at 60%.

  • On pace (green): you've used no more than the marker.
  • Slightly over (amber): up to 10 points past it.
  • Well over (red): more than 10 points past it, or 90% used.

Colour is never the only signal: every bar also says on pace or over +12%, with a symbol to match.

Features

Built for people with more than one subscription

Every Provider, side by side

Claude, ChatGPT/Codex and GitHub Copilot, only where their real figures can be read. Nothing is estimated.

A numbered widget for each Account

Agent Usage: Account 1 to 6 in the widget gallery, small or medium. Move an Account up or down to change which widget shows it.

Everything in the menu bar

Every Account's figures and status in one dropdown, with Refresh now, Manage Accounts and a Re-authorise button on each Account. It refreshes every five minutes, and the markers keep moving in between.

Never logs your tools out

Each Claude and Codex Account signs in to a folder of its own, so your everyday Claude Code and Codex logins are never read or changed. You're warned 7 days before a known expiry.

Private by design

The app fetches; the sandboxed widget only reads its snapshots. It never touches a credential or the network.

Providers

Real figures only

A Provider is added only when its real usage can be read by a program. Usage that could only be scraped or estimated is never shown.

Install

One script, from a release

You need macOS 26 or later, the GitHub CLI signed in, and each Provider's own CLI: Claude Code for Claude, the Codex CLI for Codex. Copilot needs only a token.

Releases are self-signed and not notarised, so install them with the script rather than a browser download, which Gatekeeper would block. It checks the release's SHA-256, replaces /Applications/Agent Usage.app and relaunches it.

The full install guide

Terminal
$ gh repo clone adrianeyre/agent-usage-widget
$ cd agent-usage-widget
$ scripts/install.sh          # the latest release
$ scripts/install.sh 1.2.0    # or a version
  1. Click the gauge in the menu bar, then Manage Accounts… and +.
  2. Choose a Provider and sign in in the browser, or paste a Copilot token.
  3. Right-click the desktop, Edit Widgets…, and add Agent Usage: Account 1.
